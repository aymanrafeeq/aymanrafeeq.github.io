ARC 03Jul 2026 – Present

The Ledger ArcBarakah Capital · Backend Developer · Investment platform

  • Built REST APIs in Go and PostgreSQL for investor onboarding, dashboards, deposits, withdrawals and accounts.
  • Implemented JWT auth with refresh token rotation, bcrypt hashing and Brevo email verification, written test-first.
  • Integrated Plaid KYC identity verification and bank linking, plus admin-reviewed accredited investor checks.
  • Built Stripe ACH deposits settled via webhooks into an idempotent ledger, with workers for reconciliation.
  • Implemented withdrawals via Stripe Connect payouts with admin approval, fee quotes and accounting entries.
  • Delivered Firebase push notifications, an activity feed, a document centre and e-signed account closure.
  • Deployed to a self-hosted server with Docker Compose, GitHub Actions, Tailscale and Cloudflare.
